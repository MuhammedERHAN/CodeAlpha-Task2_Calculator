**✨ ABOUT THE PROJECT** :-

Code X Calc is a modern web-based calculator focused on combining practical arithmetic functionality with a clean and responsive user interface.

Instead of building only a basic button-based calculator, the project focuses on creating a more complete interaction experience with real-time expression feedback, contextual percentage calculations, keyboard interaction, responsive behavior, input validation, and polished visual micro-interactions.

The calculator supports standard arithmetic operations including addition, subtraction, multiplication, and division, along with decimal values and percentage calculations.

This project was developed as **Task 2 of the CodeAlpha Frontend Development Internship**, with a focus on applying practical frontend development principles using HTML, Tailwind CSS, and Vanilla JavaScript.

**🚀 KEY FEATURES** :-

- 🧮 **Basic Arithmetic Operations** — Addition, subtraction, multiplication, and division
- 🔢 **Decimal Calculation Support** — Supports decimal values while preventing duplicate decimal points within the same number
- 📊 **Contextual Percentage Calculation** — Handles percentage input differently depending on the current arithmetic context
- 👀 **Real-Time Expression Preview** — Displays the current calculated result while an expression is being entered
- ⌨️ **Full Keyboard Support** — Supports numbers, arithmetic operators, percentage, decimal point, Enter, Backspace, Delete, and Escape
- 🧹 **Clear Function** — Clears the current calculator expression
- ⌫ **Backspace / Delete Function** — Removes the last entered character
- ⚡ **Instant Calculation** — Calculates expressions without page reloads
- 🛡️ **Input Validation** — Validates calculator expressions before evaluation
- ❌ **Error Handling** — Handles invalid expressions and non-finite calculation results gracefully
- 🔄 **Post-Calculation Behavior** — Automatically starts a new calculation when a number is entered after completing a calculation
- 🔢 **Result Formatting** — Reduces unnecessary floating-point precision in calculated results
- ✨ **Interactive Button Feedback** — Provides visual feedback for keyboard presses and button interactions
- 📱 **Responsive Layout** — Adapts to different viewport sizes including mobile, tablet, and desktop
- 🎯 **Touch-Friendly Controls** — Uses large circular controls designed for comfortable interaction
